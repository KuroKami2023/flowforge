# PRODUCT.md — FlowForge

## Product truth
Visual workflow automation: canvas builder (React Flow) with trigger, logic,
transform, HTTP, AI, and output nodes; server-side execution via /api with
per-node input/output run history; NVIDIA Nemotron AI nodes (server-side key);
webhook triggers (POST /api/webhooks/{workflowId}) and polling schedules
(min 5 minutes). No code editor, no build step. Node catalog on the landing
is rendered from the live NODE_DEFINITIONS palette and cannot drift.
Routes: `/dashboard`, `/login`, `/signup`.
Landing anchors (stable): `#nodes`, `#how`, `#faq`.
Primary CTA labels (stable): "Get started", "Sign in", "Open control room".
